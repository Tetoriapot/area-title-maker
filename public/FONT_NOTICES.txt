GOOGLE FONTS NOTICE
===================

Area Title Maker does not bundle font software in this repository. When a
Google Font is selected, the browser requests only the selected family,
weight, and style from fonts.googleapis.com and fonts.gstatic.com. User-entered
title text is not placed in the Google Fonts CSS request URL.

Google receives network information needed to serve these files, including the
requesting IP address. See Google's explanation:
https://fonts.googleblog.com/2022/11/your-privacy-and-google-fonts.html
